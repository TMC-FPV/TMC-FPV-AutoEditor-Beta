# TMC-FPV AutoEditor v18.6.4 — Full User Glossary

A reference guide to every main control and section in TMC-FPV AutoEditor v18.6.4, what it does, and how to use it.

## First: the three-stage workflow

The main window is organised into three balanced stages. Work left to right:

1. **Project files** — tell the editor where your footage, music, and finished video should be.
2. **Choose your edit** — select the editing approach and optional creative variation.
3. **Video output** — choose the format and quality of the finished video.

You can open **Advanced options** for more detailed control, or use the simple three-stage setup for a quick edit.

---

## Header / top area

### TMC-FPV AutoEditor title
The application name and branding area. In this build it displays the title, version/build label, and tagline: *The Lazy Persons DVR Editor*.

### Build/version label
Shows the current release version (v18.6.4). Use this when reporting a bug or asking for help so the build can be identified precisely.

### Import Footage
Opens or closes the optional import panel. This panel is centred above the three main stages. It is a convenience for bringing source footage into your selected footage folder before scanning.

### PC INFO
Opens a separate information window with the hardware/CPU summary, encoder information, and the rough render-time estimate. The Work Edition uses CPU encoding with FFmpeg/libx264 rather than relying on GPU encoder support.

### DARK MODE / LIGHT MODE
Switches the colour theme. The layout and control positions remain the same; only the theme colours change. The button names indicate the theme you can switch **to**.

## Optional Import Footage panel

Import is optional. If your videos are already in your footage folder, skip this panel and use **Scan Footage**.

### Source
Choose the source type:
- **YouTube** — use a YouTube video, playlist, channel, or supported URL. The app uses yt-dlp for downloading.
- **Google Photos shared album** — the app opens the shared album in your browser. Google Photos bulk download is a browser-assisted workflow rather than a direct yt-dlp download.

### Download quality
For YouTube, choose the desired download quality:
- **480p** — smaller download, lower detail.
- **720p** — a practical balance of size and quality.
- **1080p** — higher detail, larger downloads.
- **Best available** — allow yt-dlp to select the best available format.

### Video / playlist / channel / shared album URL
Paste the source URL here. For YouTube, use the video, playlist, channel, or other supported yt-dlp URL. For Google Photos, paste the shared album URL.

### Choose destination…
Select the folder where downloaded/imported media should be saved. Ideally this is the same folder you will use as **Footage folder** in Stage 1.

### DOWNLOAD
Starts the yt-dlp download for supported YouTube URLs. It is enabled when the app has the required URL and destination information and the downloader is ready.

### OPEN GOOGLE PHOTOS LINK
Opens the shared Google Photos album in your browser. Use Google Photos' **Download all** option, save the downloaded archive to the chosen destination, extract the contents into that destination folder, then return to AutoEditor and scan that folder.

## Stage 1 — Project files

This stage defines the source material and where the finished render will be written.

### Footage folder
The folder containing video clips to edit. The editor scans this folder and its subfolders for supported video files.

**How to use:** Click **Browse…** and select your footage folder. If using the import panel, make the import destination and this folder match, or copy/extract the imported videos into this folder.

### Music file
The soundtrack for the finished edit.

**How to use:** Click **Browse…** and select a supported audio file (for example MP3, WAV, M4A, AAC, FLAC, or OGG). If you want to use a different song, replace this selection before generating.

### Output file
The full save path and filename for the final video.

**How to use:** Click **Browse…**, choose where to save, and enter a filename. The output is expected to be an MP4 file; include the `.mp4` extension.

## Stage 2 — Choose your edit

This stage sets the broad editing approach. Presets can configure several related settings together, or you can choose the editing style and use Advanced options to fine-tune.

### Editing style
Choose the general editing approach:
- **Story arc (recommended)** — the default story-led option; intended to structure footage as a progression rather than simply shuffle clips.
- **FPV action / fast cuts** — suited to high-energy footage and quicker edits.
- **Retro documentary / long shots** — favours a retro/camcorder treatment and longer clip lengths.
- **Rhythm-focused** — editing approach intended to emphasise musical rhythm.
- **Random montage** — a more randomised montage approach.

### Quick preset
A shortcut for applying a set of related editing settings. Selecting a preset alone does not apply it; use **Apply**.

#### Preset behaviours in v18.6.4
| Preset | Editing style | Retro look | Random transitions | Min clip | Max clip |
|---|---|---:|---:|---:|---:|
| Custom | No preset applied | — | — | — | — |
| FPV Action | FPV action / fast cuts | Off | On | 1.5 s | 4.0 s |
| Long Range | Story arc (recommended) | Off | Off | 4.0 s | 8.0 s |
| Retro Camcorder | Retro documentary / long shots | On | Off | 5.0 s | 12.0 s |
| Music Video | Rhythm-focused | Off | On | 2.0 s | 6.0 s |

**How to use:** Choose a preset and click **Apply**. Presets set the editing style, retro look, random-transitions toggle, and minimum/maximum clip duration. You can subsequently change any of these in the main controls or Advanced options.

### Apply
Applies the selected preset's settings. **Custom** is not a preset configuration and pressing Apply with Custom does not apply a preset.

### Artistic Mode — automatic creative variation
Optional toggle for added creative variation during the edit. It is designed as a simple on/off choice; it does not ask you to configure a separate set of creative parameters.

## Stage 3 — Video output

These settings define the format of the finished render.

### Resolution
Choose the output size:
- **720p** — HD; usually quicker to render and smaller output files.
- **1080p** — Full HD; more detail and generally a larger/longer render.
- **1440p** — higher-resolution output; generally the most demanding of the available choices.

### Aspect ratio
Choose the intended frame shape:
- **16:9 Landscape** — conventional widescreen video.
- **1:1 Square** — square frame.
- **9:16 Vertical (crop)** — portrait/mobile format, with the source framed/cropped to fit.

### Quality
Choose the encoding quality/size trade-off. The labels are FFmpeg CRF settings:
- **Standard (CRF 23)** — smaller/lower-quality encode relative to the other choices.
- **High (CRF 20)** — default balance of quality and file size.
- **Very high (CRF 18)** — higher-quality encode, generally larger file.

### Frame rate
Choose the output frame rate:
- **30 fps** — standard choice for many videos and a lighter render.
- **60 fps** — smoother motion when suitable source footage is available; increases processing demands.

## Advanced options
Advanced options can be expanded or collapsed using the **Advanced options** bar. They are intended for users who want to control clip lengths, source ordering, effects, highlight timing, music sections, and optional intro/logo media.

### Clip selection

#### Minimum clip (s)
The lower target limit for clip duration in seconds. Lower values allow more frequent cuts and more clips.

#### Maximum clip (s)
The upper target limit for clip duration in seconds. Higher values allow longer shots and fewer cuts.

**Tip:** Keep the minimum less than or equal to the maximum. Very short clips suit fast action; longer ranges can create a calmer, more documentary edit.

#### Source order
- **Random** — footage source ordering can be randomised.
- **Chronological** — source ordering follows the footage's chronological/file sequence where the editor can establish it.

#### Edit highlight schedule…
Opens a text-style list for identifying moments you want the edit to prioritise. Enter one highlight per line using the source filename (extension optional) and a timestamp.

**Format:** `Filename, timestamp`

**Example:** `Flight3, 00:02:14`

Timestamps can be `MM:SS` or `HH:MM:SS`. Use the clip's filename and the timestamp within that video. Click **Accept** to validate and save the schedule; **Cancel** closes without committing changes. The status below the button indicates whether highlights are scheduled.

#### Edit music trim schedule…
Allows you to use one or more sections of the selected music track instead of using the full track untouched.

**Format:** `Start, End` — one section per line.

**Example:** `01:05, 01:35`

Timestamps can be `MM:SS` or `HH:MM:SS`. End must be later than start and each section must be at least 0.25 seconds. Multiple sections are joined with short crossfades. When trimmed music is used, automatic fades are applied at the beginning/end of the assembled music; full-track mode remains untouched. Click **Accept** to validate/save or **Cancel** to discard. The status text tells you whether a schedule is active or the full track is untouched.

### Effects

#### Retro handheld / camcorder look
Toggles the retro-style image treatment.

#### Fade video in
Adds a fade at the beginning of the finished video.

#### Fade video out
Adds a fade at the end of the finished video.

#### Random transitions
Allows transition choices to vary randomly rather than using a fixed selection pattern.

#### Transition strength
Sets how pronounced transitions should be:
- **Subtle** — restrained transitions.
- **Balanced** — moderate transition strength (default).
- **Strong** — more noticeable transitions.
- **Heavy** — strongest transition treatment.

#### Vertical footage
Controls how vertical source clips are handled:
- **Original (fit)** — fits the original clip within the output frame rather than applying the zoom option.
- **50% zoom** — applies additional zoom to vertical footage, changing the visible crop/framing.

### Intro / logo

#### Include intro/logo
Enable or disable adding a selected intro video or still image before the main edit.

#### Intro/logo file field
Shows the selected intro/logo media path.

#### Browse…
Select an intro/logo file. Supported choices include video formats and still images (PNG/JPG/JPEG). For a still image, the **Still-image duration** setting controls how long it is displayed. For video, the duration is read from the selected file when possible.

#### Still-image duration (s)
How long the selected still-image logo/intro is shown, in seconds. Only applies to still images.

#### Random seed
A numeric seed that controls reproducible random choices where the edit uses seeded randomness. Leave blank for automatic randomness. Reusing the same seed with the same inputs/settings can help reproduce a similar randomised edit.

#### Copy seed
Copies the current seed value so it can be reused or shared.

## Controls / action bar

Buttons are presented in uppercase for a consistent interface style.

### SCAN FOOTAGE
Scans the selected footage folder and prepares the editor's source-footage information. Run this after changing the footage folder or adding/removing clips. A scan is needed before generation.

### CANCEL SCAN
Stops an active footage scan.

### GENERATE VIDEO
Starts the video-generation process using the current project, edit, advanced, and output settings. The button becomes available when the required setup is ready.

### GENERATE AGAIN
Starts another generation using the current settings but allows a new randomised result. Useful when you like the overall approach but want a different arrangement.

### CANCEL RENDER
Requests cancellation of an active render.

### CHECK PROJECT
Runs a pre-flight check of the footage folder, music file, output path/extension, clip-length values, seed (if entered), intro/logo path (if enabled), and FFmpeg readiness. It reports any issues or confirms that the project looks ready.

### OPEN OUTPUT FOLDER
Opens the folder containing the selected output file.

### PLAY FINISHED VIDEO
Attempts to open the finished output video using the system's associated player.

### COPY LOG / ERROR DETAILS
Copies the timestamped activity log to the clipboard. This is useful when reporting a problem.

## Progress and activity area

### Progress/status text
Shows what the app is currently doing and, when available, progress percentage or render estimate. During scanning, downloading, and rendering, it changes to reflect the current activity.

### Progress bar
Visual indication of scan/download/render progress. The app may use a determinate percentage or an activity state depending on the task.

### Activity / log
Timestamped messages from setup, scanning, downloading, rendering, warnings, and errors. Use this as the first place to look when something seems stalled or fails.

## A recommended first-use workflow

1. Select your **Footage folder**.
2. Select your **Music file**.
3. Set the **Output file**.
4. Choose an **Editing style**, or select a **Quick preset** and click **Apply**.
5. Choose **Resolution**, **Aspect ratio**, **Quality**, and **Frame rate**.
6. Optional: expand **Advanced options** and adjust clip lengths, effects, highlights, music trims, or intro/logo.
7. Click **CHECK PROJECT** and resolve any warnings.
8. Click **SCAN FOOTAGE**.
9. When ready, click **GENERATE VIDEO**.
10. Review the result. If you want a different random variation, use **GENERATE AGAIN**.

## Troubleshooting tips

- **No clips found:** confirm the footage folder and that supported video files are inside it (including subfolders).
- **Download won't start:** confirm source URL, destination folder, and that yt-dlp setup is complete.
- **Output fails:** run **CHECK PROJECT** and inspect the Activity/log panel; copy the log for support.
- **Unexpected clip rhythm:** try a different editing style/preset or adjust minimum/maximum clip lengths.
- **Music feels wrong:** try a different music file or use the music trim schedule to select a more suitable section.
- **Portrait framing looks off:** try the other vertical footage option or select a suitable output aspect ratio.
